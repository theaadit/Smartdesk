SmartDesk 📂

SmartDesk is a Python-based file organization tool designed to simplify file management by automatically categorizing files according to their extensions.

Built using Python's `pathlib` and `shutil` libraries, SmartDesk scans a selected folder, creates category folders, and copies files into the appropriate locations while preserving the original files.

### Features

-Automatic File Categorization:** Organizes images, videos, documents, applications, music, code files, and other files.
-Automatic Folder Creation:** Creates category folders when they don't already exist.
-Duplicate Filename Handling:** Generates unique filenames to avoid overwriting existing files.
-Safe File Copying:** Preserves original files by copying rather than moving them.
-Basic Error Handling:** Reports file-copying failures.
-File Report:** Displays the number of files successfully copied into each category.

### Technologies Used

- Python
- pathlib
- shutil

### Project Goal

SmartDesk is a learning-focused project built to develop practical Python programming skills, filesystem handling, automation, and error handling.
